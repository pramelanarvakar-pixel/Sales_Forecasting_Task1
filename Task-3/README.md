# Task 3 - Resume / Candidate Screening System

Build an ML system to automatically screen and rank resumes based on job role.

## Tools
Python, Scikit-learn, TF-IDF, Cosine Similarity

## Key Features
- Resume text cleaning & parsing
- Skill extraction & matching
- Candidate ranking based on role fit
- Skill gap identification (missing skills)

## How it Works
1. Cleans Job Description and Resumes
2. Converts text to TF-IDF vectors
3. Calculates cosine similarity for ranking
4. Shows Found and Missing Skills

## Result
System ranks candidates and highlights who is best fit for Data Scientist role.
